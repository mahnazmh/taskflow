# TaskFlow – Task Management App

TaskFlow is a responsive task management application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Set task priorities (High, Medium, Low)
- Mark tasks as completed or undo completion
- Filter tasks by All, Today, and Completed
- Automatically update task statistics
- Save tasks using Local Storage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Run `index.html` using Live Server.

## Data Storage

TaskFlow uses the browser's Local Storage to save tasks. Data remains available in the same browser on the same device.
